# Mikro elementlar ilovasi

O'zbek tilida mikroelementlar, makroelementlar va vitaminlar bo'yicha qo'llanma.

Jonu ishlaydigan manzil: https://abrorsayitov-prog.github.io/mikro-elementlar-ilovasi/

To'rt panel:

- **Barchasi** — har element uchun kunlik norma, tanqislik belgilari va oziq-ovqat manbalari.
- **Minerallar** — element → tanqisligida rivojlanadigan kasalliklar, va oziq-ovqat → tarkibidagi elementlar + 100 g dagi aniq tarkibi (mg/mkg).
- **Kasalliklar** — kasallik bo'yicha bolalar / ayollar / erkaklar uchun kunlik me'yor va ertalab / obed / kechga uchun taxminiy menyu.
- **Hisoblagich** — ovqatlarni porsiyon bilan tanlab, kunlik me'yorga qancha element to'planishini foiz va chiziq bilan ko'rsatadi (64 mahsulot, 100 g dagi tarkib bo'yicha).

## Eslatma

Ma'lumotlar xalqaro tavsiya etilgan kunlik me'yorlardan (RDA/AI) olindi va faqat
ma'lumot berish maqsadida. Aniq tashxis va davolash dozalarini shifokor belgilaydi.

Oziq-ovqat tarkibi — 100 g uchun o'rtacha qiymatlar (pishirilgan/uxatlangan holatga
 qarab farq qiladi). Hisoblagichdagi «Bolalar» = 4–8 yosh, «Ayollar» = 19–50,
«Erkaklar» = 19+ yosh me'yorlari. Kobalt va Kremniy uchun RDA belgilanmagan.
