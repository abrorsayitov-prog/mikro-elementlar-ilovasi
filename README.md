# Mikro elementlar ilovasi

O'zbek tilida mikroelementlar, makroelementlar va vitaminlar bo'yicha qo'llanma.

Uch panel:

- **Barchasi** — har element uchun kunlik norma, tanqislik belgilari va oziq-ovqat manbalari.
- **Minerallar** — element → tanqisligida rivojlanadigan kasalliklar, va oziq-ovqat → tarkibidagi elementlar.
- **Kasalliklar** — kasallik bo'yicha bolalar / ayollar / erkaklar uchun kunlik me'yor va ertalab / obed / kechga uchun taxminiy menyu.

## Ishga tushirish

```
python3 -m http.server 8000
```
